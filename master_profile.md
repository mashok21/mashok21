## 4. austrianprocess.com

Source: read directly from the `austrianprocess` codebase (`/home/ashok/projects/austrianprocess`, both frontend and backend repos), not LinkedIn. Facts below are traced to specific files; see inline citations.

**Live URL:** https://www.austrianprocess.com

**What it is:** An educational platform translating Austrian School economics (Mises, Hayek, Lachmann, Böhm-Bawerk, Rothbard, and others) into interactive tools and data dashboards. Tagline: "Austrian Economics, applied." (`frontend/public/index.html`, `frontend/src/pages/LandingPage/index.js`)

It ships eight tools, each its own route: Why Austrian (a practitioner critique of mainstream equilibrium models), the Garrison Triangle, live FRED interest-rate telemetry with historical crisis annotations, a central-planning simulator built around Mises's economic calculation argument, the Ask Austrian RAG chatbot, a scored quiz on Austrian concepts, a curated reading shelf, and long-form explainers.

**The Hayekian-Garrison Triangle:** `frontend/src/components/GarrisonTriangle/index.js`, rendered at `/garrison-triangle`. A hand-built inline SVG, not a chart-library visualization. It is driven by a single time-preference slider (1–9): moving it interpolates two triangles, an "Initial Phase" and a "Later Phase," showing how time preference (savings versus consumption) determines the length of the production structure and how that investment compounds into future output. No live screenshot existed anywhere in the repo (there was one unused, orphaned reference PNG that isn't what the live tool actually renders), so a fresh screenshot was captured directly from the live public page and saved to `public/images/garrison-triangle.png` for use on this site.

**The RAG system, "Ask Austrian":** A two-service architecture, documented in `backend/README.md`:
React frontend → Express gateway (`server.js`) → FastAPI service (`app.py`) → LangGraph agent (`agent.py`) → MongoDB Atlas Vector Search (`ragchunks` collection) → local `sentence-transformers` embeddings (`all-MiniLM-L6-v2`) → Gemini (`gemini-3.6-flash`) as primary LLM with Claude (`claude-sonnet-5`) as automatic fallback.

The agent is a compiled LangGraph state graph (`check_advice → retrieve → generate → guard_compliance`) with per-session conversation memory. It retrieves from a governed corpus of 28 primary-source texts (Mises's *Human Action*, *Socialism*, *The Theory of Money and Credit*; Rothbard's *Man, Economy, and State*, *America's Great Depression*; Menger's *Principles of Economics*; Böhm-Bawerk's *The Positive Theory of Capital*; Hayek, Hoppe, Lachmann, Horwitz, Boettke and others), tracked with SHA-256 provenance and typed eligibility status in `corpus/manifest.json`. Two independent, cross-language guardrails (a shared regex pre-filter and a post-generation compliance scan) stop it from giving financial or investment advice, refusing and overwriting any response that reads as advice.

**Other applied-capability highlights, for use if the page has room:**
